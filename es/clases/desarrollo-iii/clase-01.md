# Introducción a Desarrollo III


## Variables en Python

En Python, una **variable** es un espacio en la memoria que almacena un valor.

### Declaración de variables

```python
nombre = "Juan"
edad = 25
estatura = 1.75
activo = True
```

### Tipos de variables

| Tipo | Descripción | Ejemplo |
|-----|-------------|--------|
| `str` | Texto | "Juan" |
| `int` | Entero | 25 |
| `float` | Decimal | 1.75 |
| `bool` | Booleano | True / False |

### Operaciones con variables

```python
nombre = "Juan"
edad = 25
estatura = 1.75
activo = True

print(nombre)
print(edad)
print(estatura)
print(activo)
```
---

## Constantes en Python

En Python, una **constante** es un valor que no cambia durante la ejecución del programa.

### Declaración de constantes

```python
NOMBRE = "Juan"
EDAD = 25
ESTATURA = 1.75
ACTIVO = True
```
