# Introducción a Sistemas Operativos
<br>

![Imagen de sistemas operativos](https://imecaf.com/blog/wp-content/uploads/Sistemas-Operativos-1.jpg){: width="50%" height="auto"}

## ¿Qué es un SISTEMA?
<br>

### Definición

`Es un conjunto de componentes que trabajan juntos para lograr un objetivo común.`

### Características

- Constitución: física o abstracta
- Origen: natural o artificial
- Naturaleza: abierta o cerrada
- Ejecución: manual o automática
- Duración: temporal o permanente
- Comportamiento: determinístico o probabilístico

<br>

### Propiedades


- Totalidad
- Sinergia
- Recursividad
- Estabilidad
- Entropía

<br>

## ¿Qué es un SISTEMA OPERATIVO?
<br>

### Definición

```
Es un conjunto de software (programas) que
permite gestionar y administrar los recursos de 
hardware de un dispositivo electrónico y 
proporcionar una interfaz para que el usuario 
pueda interactuar con el dispositivo.
```
