# 1. El Sistema Operativo y sus partes
<br>

> ¿Puede un programa, por sí solo, manejar la memoria o los dispositivos de entrada y salida? (HARDWARE)
<br>

## Roles del Sistema Operativo
<br>

| Rol            | Descripción                                             |
|----------------|---------------------------------------------------------|
| Gestor de hardware | Administra CPU, memoria, disco, periféricos. Garantiza que todos los programas tengan acceso a los recursos cuando los necesitan. |
| Intérprete de comandos | Traduce las instrucciones del usuario (texto o clicks) a un lenguaje que la máquina entienda. |
| Intermediario  | Actúa como puente entre el usuario y el hardware.         |
| Gestor de archivos | Organiza, crea, elimina y accede a archivos y carpetas.   |
| Gestor de procesos | Controla la creación, ejecución y finalización de programas (procesos). |
| Gestor de red | Administra la comunicación con otros dispositivos.|
| Gestor de seguridad | Controla el acceso a los recursos del sistema.| 

<br>

## Partes del Sistema Operativo
<br>

| Parte | Función |
|-------|---------|
| **Núcleo (Kernel)** | Es la parte central del sistema operativo. Controla el hardware y coordina el funcionamiento del sistema. |
| **Interfaz de usuario (Shell o GUI)** | Permite que el usuario interactúe con el sistema mediante comandos o ventanas e íconos. |
| **Sistema de archivos** | Organiza la información en archivos y carpetas dentro de los dispositivos de almacenamiento. |
| **Controladores (Drivers)** | Programas que permiten que el sistema operativo se comunique con dispositivos como impresoras, teclados o placas de red. |
| **Servicios y utilidades** | Herramientas que realizan tareas del sistema, como administrar usuarios, redes o copias de seguridad. |

## Consigna:
<br>

> Elegir un sistema operativo (por ejemplo: Windows 11, Ubuntu, Android, otro) e investigar:

1. ¿Qué hardware puede administrar?
2. ¿Cómo interactúa el usuario con él?
3. ¿Cómo organiza archivos y carpetas?
4. ¿Qué programas puede ejecutar?
5. ¿Cómo se conecta a una red o a internet?
6. ¿Qué medidas de seguridad posee?
7. ¿Qué ocurre cuando el sistema operativo inicia?
